## How I work on a project

1. **Understand the need:** meet the client, clarify the expected behavior, study what standard Odoo already does.
2. **Specify:** write the functional and technical specification, estimate the effort.
3. **Build:** configure first, develop only what is needed, extend standard Odoo by inheritance to keep upgrades easy.
4. **Test:** functional tests on a test database before anything reaches production.
5. **Deploy:** Ubuntu or Docker (Odoo, PostgreSQL, Nginx), Git branches and controlled releases.
6. **Train and support:** user training, demonstrations and follow-up after go-live.
